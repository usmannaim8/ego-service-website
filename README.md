# EGO SERVICE PHASE 1

This branch establishes the Phase 1 visual foundation for the Ego Service corporate platform.

## Public experience
- Corporate homepage with hero, services, projects, country presence, CTA
- About, services, projects, contact, country pages, international ops pages
- Employee login entry

## Private experience
- Employee portal dashboard concept with mock data
- Subsidiary dashboard concept
- Documents, trackers, signatures placeholders

## Administration experience
- Admin overview and staffing screens
- Subsidiary and workflow views
- Audit log and permissions overview

## Technical structure
- Shared CSS cleanly split into `assets/css/main.css`
- Shared JS at `assets/js/main.js`
- Mock data at `assets/js/data/mock-data.js`
- Screens built with HTML placeholders and realistic sample data

## Important notes
- This is a visual system first, not a backend implementation.
- Real security, auth, and database work are intentionally deferred to later phases.
- Public company information remains placeholder-based until verified.
