# Ego Service - Professional Trading Website

## Overview
Ego Service is a professional trading website offering comprehensive financial trading solutions. This is a fully responsive, modern website built with HTML5, CSS3, and vanilla JavaScript.

## Features

### Pages
1. **Homepage (index.html)**
   - Hero section with call-to-action
   - Features showcase
   - Call-to-action section

2. **Services (services.html)**
   - Stock Trading
   - Forex Trading
   - Cryptocurrency Trading
   - Commodities Trading

3. **About (about.html)**
   - Company story
   - Mission statement
   - Core values
   - Team information

4. **Contact (contact.html)**
   - Contact form
   - Business information
   - Social media links
   - Operating hours

### Design Features
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with gradient backgrounds
- **Navigation**: Sticky navigation bar with mobile hamburger menu
- **Accessibility**: Semantic HTML and accessible form elements
- **Performance**: Optimized CSS and lightweight JavaScript

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/usmannaim8/ego-service-website.git
```

2. Navigate to the project directory:
```bash
cd ego-service-website
```

3. Open `index.html` in your web browser or use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (if installed)
npx http-server
```

4. Open your browser and visit `http://localhost:8000`

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #1a73e8;
    --secondary-color: #34a853;
    --dark-color: #202124;
    --light-color: #f8f9fa;
    --text-color: #3c4043;
}
```

### Content
- Edit HTML files to update page content
- Modify text, images, and links directly in the HTML

### Styling
- Modify `styles.css` for design changes
- Update colors, fonts, spacing, and layout
